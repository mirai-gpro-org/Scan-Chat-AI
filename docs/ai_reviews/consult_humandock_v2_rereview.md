## 2. 絶対要件（変更不可の前提）
- **漏れなし（絶対）**：元の検査票にある数値は必ず入れる。運用的意味＝**サイレント脱落ゼロ（必ず検知して再読にかける）＋読み切る**。
  - 補足：確率モデル単体で「常に完全JSON」を**数学的に保証することは不可**（両者合意）。実装可能な保証は「**値を黙って失わない**」まで。目標は人手ゼロ・捏造ゼロで漏れ/余剰/誤りを**限りなく0**。
- **捏造ゼロ**（読めない値を平均/前回/基準で埋めない）。**人手介入100%不可（全自動）**。
- **①読取プロンプト凍結・入力画像不変**（主パスへの摂動は numeric 回帰の実績）。補修は**後段のみ**。
- **1画像=1リクエスト・Vercel 60s**／`gemini-3.1-flash-lite`・temp0／様式は4種以上と多様／追加依存は最小（`sharp` 導入済）。
- 各後段機能は **env gate 既定オフ＋🎯ゴールデンで numeric 全一致・False-Value 0 を確認してから有効化・回帰したら即オフ**。

## 3. 修正後アーキテクチャ（全体）
**中核原則：モデル出力を起点にせず、"画像証拠候補"と"主パス出力"の双方向照合で確定する。**

```
[前処理(ローカル/sharp・意味を読まない)]
  画像正規化 → テーブル候補 → 列候補(今回/前回/基準/単位) → 今回列 occupied セル検出
        ▼ 並列（外部呼び出し直列は2段まで）
  Gemini A：現行主パス(10列Markdown・bbox なし・不変)
  Gemini B：ラベル/テーブル意味 補助パス(occupied セルの行のみ)
        ▼
  決定論照合：主パス出力 ↔ occupied セル候補（双方向）
        ▼ 不足/不一致のみ
  Gemini C：不足候補を「テーブル別・20〜30件・大連番ID・今回セル＋ラベルのみ(過去/基準列を含めない)」の
            コンタクトシートで一括局所VQA（必要時のみ）
        ▼
  正の証拠タイブレーク（競合時のみ）→ 概念/実体ID dedup → 残留証拠監査(reject専用)
        ▼
  双方向完全性会計 → 未解決はリトライラダーで読み切る → Elith 納品(証拠付き確定値)
```

## 4. 課題別の解（修正版）
**A（行欠落／FT3）**
- occupied-cell-first：今回列に occupied セルがあるのに主パス出力に対応が無い → その行だけ局所VQAで再読。
- 読めた値のみ充填。読めなければ捏造せず監査に残し**リトライラダー**（コントラスト/2倍/赤成分/行クロップ）で読み切る。
- **同一エンコーダ問題への三重化**：A=CV(意味を読まずインク有無/連結成分)・B=ラベル専用VLM・C=残留証拠監査。VLM 2回は独立検証にならない前提。

**B（推移グラフ混入）**
- グラフ由来値は詳細表の今回セルに裏付けが無い → **競合/重複の勝者判定で自然に落ちる**（グラフ分類の精度に安全性を賭けない）。
- 領域分類（見出し＋軸/点/凡例/低文字密度）は**補助信号・却下理由**として付すのみ。入力は改変しない。

**C（別名重複）**
- **概念ID＋実体ID**で dedup。全一致（概念/実体/時系列/検体/左右/回数）時のみ統合。
- 異値は `CONFLICT_UNRESOLVED` で保持（自動採用しない）。ただし一方だけ今回セル証拠がある場合は competition でなく `SUPPORTED / UNSUPPORTED_OUTPUT` として解決。**値一致は重複の十分条件でない**（左右/別日同値）。

## 5. 完全性の定義（修正）
- **双方向会計**：画像→出力（occupied 候補すべてに終了状態）AND 出力→画像（全主パス出力が EVIDENCE_MATCHED / UNSUPPORTED_OUTPUT / AMBIGUOUS のいずれか）。
- **保証すること**＝サイレント脱落ゼロ（値を黙って失わない）。**保証しないこと**＝常に完全JSON（確率モデル単体では数学的に不可）。
- 終端：未解決は**自動停止でなくリトライラダーで読み切る**（発注者裁定）。それでも読めない残差は捏造せず監査に残す（no silent drop は守る）。

## 6. 60s 予算（紙上で断定せず実測する）
- 外部呼び出し直列2段（A‖B → 必要時 C）。C はテーブル別 20〜30 件の一括VQA。候補過多は上限＋自動停止（`TIME_BUDGET`）で暴走防止。
- **実測が必要**：モデル呼び出し P50/P95・画像処理時間・候補数別VQA時間・同時呼び出しの 503 率をゴールデンで計測してから常用（我々の🎯規律）。

## 7. 正直な残存リスク（再レビューで潰したい核心）
