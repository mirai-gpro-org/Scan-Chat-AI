## 2. クリーンになった残差（🎯 決定論ゴールデン照合 = 54/69 = 78%）

同一画像に対する**決定論の値照合**（画像非依存の正解値と突合）。🔍が100%なのに🎯が78%なのは、**値は画像内に存在するが、行帰属／名称が主パスで崩れている**ためです。15件を4系統に分解しました（証拠付き）。

### A系統：脂質トリプルのシャッフル（＝いわゆる課題B）
正解 **LDL=47 / HDL=129 / TG=82** に対し、配信は:
- `LDLコレステロール` = [82, 129]（同名異値=collide）
- `HDLコレステロール` = 47
- `中性脂肪(TG)` = [129, 82]（同名異値=collide）

値の集合 {47,129,82} は**存在するが LDL/HDL/TG 間で回転**している。🔍 も「ページ2(推移グラフ)とページ4(詳細)の値が重複採録」と指摘。**同名異値なので dedup では潰せない**（＝自動採用は捏造リスク＝確定制約に抵触）。

### B系統：主パスの隣接行シフト（run毎に変わる非決定性）
値は読めているが**隣の行にずれて配置**される。今回 run で観測:
- ALP(157) → γ-GTP に流入（`γ-GTP=157`誤 / `ALP`=Missing、正 γ-GTP=78）
- FT3(3.1) → FT4 に流入（`FT4=3.1`誤 / `FT3`=Missing、正 FT4=1.3）
- 好塩基球 ↔ 好酸球 が相互入替（0.7 ↔ 1.6）
- コリンエステラーゼ = 28（正 384）

**run毎にシフトする行が変わる**（別 run では糖代謝ブロック HbA1c/インスリン/HOMA-R がずれる、等）。主パス起因で、単発 run の後段では過去列を持たず修復困難。

### C系統：視力/眼圧/眼底の名称つぶれ（⑧-3 様式固有）
値は在る（`右眼`=[0.4, 10.0, 異常なし] / `左眼`=[0.9, 10.0, 異常なし]）が、**行名が測定種別を失い「右眼/左眼」に潰れている**。結果、裸眼視力右/左・眼圧右/左 が Missing 扱い。
- **捏造ではなく命名構造の問題**。値域が排他（視力 0〜2.0 / 眼圧 5〜30 / 眼底=定性）なので、正準化(②)で**値域ベースに右眼/左眼→裸眼視力右左・眼圧右左へ決定論的に再命名**できる見込み（既読値の付け直し＝捏造ゼロを崩さない）。

### D系統：表記ゆれ（スキャン側が正しい可能性・捏造ではない）
- 直接ビリルビン `0.1未満`（＜0.1）vs golden `0.1`（不等号表記の差）
- ナトリウム `142.3` vs golden `142`（桁）

→ **照合器/正準化側で吸収すべき**（スキャンの方が正確な可能性）。

## 4. レビューして頂きたい論点（率直なご意見をお願いします）

1. **C（視力/眼圧の値域ベース再命名）**：値域で種別を確定する決定論を②正準化に置く方針で妥当か。危険なコーナーケース（例：白内障術後で眼圧が視力レンジに入る等）や、値域が重なる項目への一般化リスクはあるか。「右眼/左眼」以外にも同種の名称つぶれが起きやすい欄はどこか（想定して先に手当てすべきか）。

2. **A（脂質シャッフル）の決定論的な救済余地**：確定制約「同名異値は自動採用しない」を**破らずに**救える方法はあるか。
   - 例：推移グラフ領域（page2）を**証拠側で領域特定して該当値を"過去/参考"としてドロップ**し、詳細表(page4)の単独値だけ残す、は捏造ゼロと両立するか（＝グラフ由来の除外は"読み間違いの排除"であって"選択"ではない、という整理は妥当か）。
   - LDL/HDL/TG は値域が重なるため C 方式（値域再命名）は使えない、という理解で正しいか。他に決定論で効く不変量（例：TC≒LDL+HDL+TG/5 の整合チェックで回転を検出）はあるか。

3. **B（マルチRUN多数決）の設計**：
   - N はいくつが費用対効果の均衡か（3 で隣接シフトの多数決は成立するか）。
   - **行の同一性キー**をどう取るか（名称は崩れる前提。値のクラスタリング＋期待レンジで"どの行か"を推定する必要があるが、これ自体が新たな誤りを生まないか）。
   - 多数決で決められない項目（3 run で 3 通り）を **EXHAUSTED_UNRESOLVED として未納品**に落とす、で捏造ゼロと両立するか。
   - マルチRUN と A/C の後段補修の**適用順序**（多数決→正準化→dedup か、正準化→多数決か）。

4. **優先順位**：捏造ゼロを守りつつゴール（漏れ・余剰・誤りの最小化）に最短で寄せるなら、C+D を即入れ、次に A と B のどちらを先に投資すべきか。**A は"見えている余剰"（🔍が明示指摘）**、**B は"件数が最多だが非決定"**。どちらのペイオフが高いと見るか。

5. **見落としている系統**：上記4系統に**収まらない残差の型**（例：セクション別カバレッジで ⑧-4血液42/51・⑧-6甲状腺2/4 が"ページ単位脱落疑い"と出ている＝ブロックごと薄く落ちている可能性）はないか。ページ単位の脱落を早期検知する軽量な決定論指標の案があれば。
