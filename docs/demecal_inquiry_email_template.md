株式会社Leisure

いつも大変お世話になっております。
株式会社ウェルフォート（代理店コード：Q05-0010）の【氏名】と申します。

現在、貴社「Demecal Data Center（DSS Web System / dl.demecal.net）」より、

このたび、当該ダウンロード業務の効率化・取得漏れ防止のため、
「定期的に、日付範囲が重複しないよう自動でCSVを取得する仕組み」の構築を
検討しております。つきましては、実施の可否および推奨される方法について
ご相談させていただきたく、以下の点をご教示いただけますでしょうか。

■ ご確認させていただきたい点

1.【自動アクセスの可否】
　プログラム／RPA等による自動ログイン・自動ダウンロードは、
　ご利用規約・運用上、許容されますでしょうか。

2.【公式のデータ連携手段の有無】
　ポータル画面の操作に代わる、API・SFTP・所定領域へのバッチ配信など、
　データを自動連携できる公式の手段はございますでしょうか。
　（ございましたら、そちらの利用を優先的に検討したく存じます）

3.【クライアント証明書の取り扱い】
　自動化用のサーバ／端末へクライアント証明書を導入して利用することは
　可能でしょうか。また、証明書の有効期限・更新手順、複数端末での
　利用可否についてもご教示ください。

4.【認証情報の非対話利用】
　ID・パスワードをプログラムから利用する運用は問題ございませんでしょうか。
　多要素認証（MFA）等の追加認証の有無もあわせてご確認させてください。

5.【アクセス制限】
　アクセス頻度・同時接続数・アクセス可能な時間帯・IP制限など、
　遵守すべき制約がございましたらご教示ください。

6.【窓口・変更通知】
　本件の技術的なご相談窓口と、システム仕様変更・メンテナンス時の
　通知方法についてもご教示いただけますと幸いです。

お手数をおかけいたしますが、ご確認のほどよろしくお願い申し上げます。
