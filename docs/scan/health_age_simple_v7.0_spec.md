## 1. 段階フォールバック (発注者指示・確定)

```
① 正規版 CABA v5.4 (health-age.ts)
   入力不足は「合理的な方法」で補填してから算出する (実装済):
     ・MCV     … 欄が無くても 赤血球 + ヘマトクリット から算出 (normalizeMarkers)
     ・RDW     … 集団中央値 13.0 で補完
     ・hs-CRP  … 好中球%/リンパ球% (NLR) から推定 → 無ければ中央値 0.15
     ・WBC     … 検査機関ごとの桁 (/μL, ×10²/μL, ×10³/μL) を自動正規化
     ・BMI     … 身長 + 体重 から算出 (※ v5.4 は計算に使わず参考表示のみ)
   → 必須 (albumin, creatinine, glucose, lymph, mcv, alp, wbc + age) が揃えば算出。
       ↓ 揃わない
② 簡易版 CABA/PhenoAge v7.0 (health-age-simple.ts)  ← 本書
   必須 = 実年齢・アルブミン・クレアチニン ＋ (血糖 または HbA1c)
       ↓ それも揃わない
③ 算出しない。以下の定型文をそのまま提示する (値は作らない = 捏造ゼロ):
   「算出に必要なデータが不足しています。詳細は事務局へお問合せ下さい。」
   → 定数 `WELLNESS_AGE_UNAVAILABLE_MESSAGE` (wellness-age.ts)。**文言を変えない**。
```

- どの版で算出したかは `method` (`full` / `simple` / `unavailable`) として
  **API 応答・`health_age_scores.inputs.method`・ダッシュボード表示**の 3 箇所に必ず残す。
- ③ は保存しない (`health_age_scores` に null 行を作らない)。API は **422** + `message` を返す。

## 2. 想定する検査書式

移植元 HTML の説明どおり、**血球検査 (リンパ球比率・MCV・RDW)・ALP・白血球数・hs-CRP を
含まない**簡易血液検査報告書 (「メタボリックシンドローム＆生活習慣病セルフチェック」型) 向け。
総タンパク・アルブミン・AST/ALT/γ-GT・脂質・尿素窒素・クレアチニン・尿酸・血糖・HbA1c・
eGFR・身長体重・血圧・腹囲・BMI を含む書式が対象。

このため **PhenoAge 本体は実質「アルブミン・クレアチニン・血糖・実年齢」の 4 項目で駆動**され、
残りの 6 項目は常に集団中央値 (= 寄与中立) になる。**必ず「参考値」として表示すること。**

## 3. アルゴリズム (移植元の実コードから転記・推測値なし)

### 3.1 必須と代替

| 項目 | 扱い |
|---|---|
| 実年齢 (age) | 必須 |
| アルブミン (g/dL) | 必須 |
| クレアチニン (mg/dL) | 必須 |
| 血糖 (mg/dL) | 原則必須。未測定なら HbA1c から **eAG** を推定して代用 |
| HbA1c (%) | 血糖が無いときの代替 (かつ補助オーバーレイにも使う) |

**eAG (推定平均血糖)**: `eAG(mg/dL) = 28.7 × HbA1c(%) − 46.7`
出典: Nathan DM et al. ADAG Study, *Diabetes Care* 2008;31:1473–1478。
**空腹時血糖の実測ではない**ため、代用したことを結果画面に必ず明記する
(ダッシュボードは `glucoseSource === 'eag'` で注記を出す)。血糖・HbA1c の**両方**が無ければ算出不能。

### 3.2 常に中央値補完する項目 (`REF`)

| マーカー | 補完値 |
|---|---|
| hs-CRP | 0.15 mg/dL |
| リンパ球比率 | 32 % |
| MCV | 90 fL |
| RDW | 13 |
| ALP | 65 U/L |
| WBC | 5.5 ×10³/μL |

(`REF` にはこのほか albumin 4.4 / creatinine 0.85 / glucose 92 が入っているが、これらは
「中央値に置換した場合との差分」を表示するためのもので**計算には実測値を使う**。)

### 3.3 性別正規化 (`SEX_NORM`)

- **クレアチニンのみ有効** (`enabled: true`)。`creat + (0.85 − {male:0.86, female:0.63}[sex])`。
  性別未選択 (`sex = null`) は無補正。
- **アルブミンは移植元で `enabled: false`** のため補正しない (male 4.35 / female 4.25 / ref 4.3 の
  定義は存在するが未使用)。

### 3.4 PhenoAge 本体

**正規版 (CABA v5.4) と完全に同一の係数**であることを復元コードで確認した。実装は
`health-age.ts` の `phenoAgeCore` を共有する (二重管理しない)。

```
xb = −19.9067 − 0.0336·albumin(g/L) + 0.0095·creat(µmol/L) + 0.1953·glucose(mmol/L)
     + 0.0954·ln(crp) − 0.0120·lymph + 0.0268·mcv + 0.3306·rdw + 0.0019·alp
     + 0.0554·wbc + 0.0804·age
g = 0.0076927 ;  M = 1 − exp(−exp(xb)·(exp(g·120) − 1)/g)
pheno = 141.50225 + ln(−0.00553·ln(1 − M)) / 0.090165
```

### 3.5 補助オーバーレイ (PhenoAge 外・非原著)

`adj = clamp((dir==='higher' ? v − ref : ref − v) × slope, −cap, +cap)` を合計する。空欄は加算しない。

| id | 表示名 | ref | slope | cap | dir |
|---|---|---|---|---|---|
| `sbp` | 収縮期血圧 | 120 | 0.06 | 3 | higher |
| `dbp` | 拡張期血圧 | 80 | 0.08 | 2 | higher |
| `ua` | 尿酸 | 6 | 0.3 | 2 | higher |
| `egfr` | eGFR | 90 | 0.04 | 3 | **lower** |
| `hba1c` | HbA1c | 5.5 | 1.2 | 3 | higher |
| `ldl` | LDL-C | 120 | 0.02 | 1.5 | higher |
| `tg` | 中性脂肪 | 100 | 0.008 | 1.5 | higher |
| `ggt` | γ-GT | 30 | 0.02 | 1.5 | higher |
| `bun` | 尿素窒素 | 15 | 0.05 | 1.5 | higher |
| `bmi` | BMI | 22 | 0.15 | 2 | higher |

**腹囲は別扱い** (基準が性別で変わるため): `ref = female ? 90 : 85`、`slope 0.08`、`cap ±2`。

> これらは PhenoAge 原著の構成要素ではない。移植元も「**係数・基準値は暫定値であり、自院コホートでの
> 再較正を前提とする**」と明記している。対外資料にはこの但し書きを必ず添えること。
> 正規版 (v5.4) のオーバーレイ (SBP・FEV1/FVC・合計 ±4) とは**別物**なので混同しない。

### 3.6 最終圧縮とクランプ

```
raw   = pheno + overlayTotal
delta = raw − age
bio   = clamp(age + 5·tanh(delta / 5), 18, 95)   // 小数第1位に丸め
```

実年齢 ±5 歳付近へなだらかに漸近する連続カーブ (急なカットオフではない)。
**正規版にはこの圧縮が無い** (正規版はオーバーレイ合計を ±4 にクランプするだけ) ので、
同じ検体でも両版の値は一致しない。**版を併記せずに数値だけを比較しない。**

## 4. 移植の根拠と検証 (R1/R2/R3)

### 4.1 移植元の復元方法

配布された HTML の JS は javascript-obfuscator で難読化されていた (文字列テーブル + 数値の
算術式化 + console 無効化の自己防衛)。**推測で書かず**、以下の手順で実コードを復元してから転記した。

1. スクリプトを Node の `vm` サンドボックス (DOM スタブ + 隔離した console) で実行し、
   文字列デコーダ `_0x1943` を取り出す。
2. デコーダの別名 (`const _0xAAAA = _0x1943` の推移閉包) を解決し、`alias(0xNNN)` を
   復号済み文字列リテラルへ置換。
3. `-1644 + -8*1061 + 10137` のような算術式に散らされた数値定数を定数畳み込みで復元。
4. `phenoAge` / `overlay` / `normalizeBySex` / `estimateGlucoseFromHbA1c` / `calculate` を
   読める形にして、**係数・基準値・キャップ・圧縮幅・クランプをすべて実コードから転記**。

### 4.2 数値照合 (実ブラウザ vs TypeScript 移植)

移植元 HTML を Chromium で実行してフォームへ入力 → 表示された「生物学的年齢」と、
`computeSimpleHealthAge` の出力を比較した。**9 ケースすべて一致 (差 0.0)**。

| # | ケース | 入力の要点 | HTML | TS 移植 |
|---|---|---|---|---|
| A | 男・基本 | 45歳 alb4.3 cre1.15 glu130 | 44.9 | 44.9 |
| B | 女・基本 | 52歳 alb4.1 cre0.62 glu98 | 47.6 | 47.6 |
| C | 性別未選択 | 60歳 alb4.5 cre0.9 glu105 | 55.4 | 55.4 |
| D | HbA1c 代用 | 58歳 alb4.0 cre1.0 **HbA1c6.4** (eAG 137) | 58.2 | 58.2 |
| E | フル入力 男 | 54歳 + オーバーレイ10項目 + 腹囲74 | 55.0 | 55.0 |
| F | フル入力 女 | 66歳 + オーバーレイ10項目 + 腹囲96 | 62.6 | 62.6 |
| G | 極端に良い | 70歳・全項目良好 (overlay −8.96) | 65.0 | 65.0 |
| H | 極端に悪い | 35歳・全項目不良 (overlay +22.05) | 40.0 | 40.0 |
| I | 女・eAG+腹囲 | 48歳 HbA1c7.2 腹囲92 BMI24 | 51.3 | 51.3 |

G/H は tanh 圧縮が効いて実年齢 ±5 歳で頭打ちになることの確認を兼ねる。

## 5. 実装上の注意

- **`normalizeMarkers` に簡易版用の同義語を追加済み** (`hba1c` / `ua` / `egfr` / `ldl` / `tg` /
  `ggt` / `bun` / `waist` / `dbp`)。正規版 (v5.4) の `REQUIRED` には一切入れていないので、
  **既存の正規版の算出結果は 1 件も変わらない**。
- 血圧は「130/84」形式の 1 セルからも収縮期・拡張期を拾う (`normalizeMarkers` の fallback)。
- 簡易版で算出した検体は `imputed_markers` に常に `crp, lymph, mcv, rdw, alp, wbc` が入るため、
  ダッシュボードでは自動的に**「参考値」バッジ + 補完の注記**が出る。
- 例外運用の合成補完 (`syntheticMarkers`) は簡易版の項目も受け付ける (`SYNTH_ALLOW` に追加済み)。
  合成は**ハードゲートより前**に適用されるので、合成で埋めた検体は①を通る。

## 6. 未確定・要確認

- 簡易版オーバーレイの係数は移植元どおり**暫定値**。再較正の要否・時期は Wellfort 判断。
- 正規版と簡易版で値が一致しない (§3.6) ため、**同一利用者の時系列に両版が混在**すると
  グラフに段差が出る。現状は `method` を残すだけで、グラフ側の区別表示は未実装。
- 対外資料 (レポート・説明資料) の免責文を「簡易版で算出した場合」に合わせて分岐させるかは未確定。
  現状はダッシュボードの「算出方法について」内に簡易版の説明を出し分けている。
