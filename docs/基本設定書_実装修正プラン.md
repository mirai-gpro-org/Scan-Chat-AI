## 1. 目的と原則

基本設定書の【元画像の検査結果を、正確に（①漏れなく ②捏造なく ③不要は落として）業界標準の項目名・単位で、Elith と決めた JSON にする】を実装で達成する。原則は基本設定書と同一：

- **①読取（Perception）は変えない**。読取揺れの是正は VQA 第2パス（①レイヤ）が担当。②は名寄せ/単位/余剰・不足のみ。**層を混ぜない**。
- **決定論・保守的マッピング・捏造ゼロ**：高信頼で写像できた時だけ正準化。不能は元のままフラグ。余剰は自動削除せず監査記録（silent drop しない）。
- **段階導入＋🎯回帰ゲート**：各フェーズは代表ゴールデンで numeric 全一致・False-Value 0 を確認してから次へ。回帰したら env で即オフ（ロールバック）。

## 5. 受入基準（全フェーズ共通・🎯回帰ゲート）

`scan_golden_healthcheckup_20250123.md` を再RUN→照合器（`elith-batch.astro goldenCheck`）で以下を確認：

- **numeric 全一致を維持**（正準化は numeric を壊さない＝最重要の非回帰条件）。
- **False-Value = 0**（未実施を埋めない・過去値を今回にしない）。
- **Missing 減 or 不変**（名寄せで偽Missing が減る／実落ちは増やさない）。
- **定性一致率・Semantic-Tie(残) が悪化しない**。
- 正準化 before/after を**監査ログに残す**（Elith 納品 data には含めない）。

## 6. リスクとロールバック

| リスク | 緩和 |
|---|---|
| 誤マップ（別項目へ写像）＝捏造 | **保守的マッピング**（高信頼のみ）。非hitは正準化せず元名＋フラグ。deny リストで危険同義語を除外 |
| numeric 回帰（過去の対策A/O-X列と同じ轍） | ②は**読取に触れない**（後段のみ）。env `SCAN_CANONICALIZE=off` で即ロールバック。🎯ゲート必須 |
| マスタ捏造（存在しない標準名） | starter は**ゴールデン実在項目のみ**。完全版は HASTOS/Elith 受領（R3） |
| 空スロット削除で実施済を落とす | S4 は既存 `sanitize` の未測定除外に一致。VQA（①）で今回値を先に確定 |
